# 04 Data Structures and Algorithms

Understanding how to store and manipulate data efficiently is crucial.

## Big O Notation
Big O describes the performance or complexity of an algorithm.
- **O(1):** Constant time.
- **O(log n):** Logarithmic time.
- **O(n):** Linear time.
- **O(n^2):** Quadratic time.

## Core Data Structures
- **Arrays:** Contiguous memory. Fast access, slow insertion/deletion in the middle.
- **Linked Lists:** Elements point to the next. Fast insertion/deletion, slow access.
- **Hash Tables (Dictionaries/Maps):** Key-value stores. Fast average case lookups.
- **Trees (e.g., Binary Search Trees):** Hierarchical data. Good for searching.
- **Graphs:** Nodes connected by edges. Used for networks, routing.

## Core Algorithms
- **Sorting:** QuickSort, MergeSort.
- **Searching:** Binary Search, Depth-First Search (DFS), Breadth-First Search (BFS).
