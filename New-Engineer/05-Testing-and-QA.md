# 05 Testing and Quality Assurance

Testing ensures your code works as expected and prevents future regressions.

## Types of Testing
- **Unit Testing:** Testing individual components or functions in isolation.
- **Integration Testing:** Testing how different components interact.
- **End-to-End (E2E) Testing:** Testing the entire application flow from the user's perspective.

## Test-Driven Development (TDD)
A process where you write the test *before* the code.
1. **Red:** Write a failing test.
2. **Green:** Write the minimal code to pass the test.
3. **Refactor:** Improve the code without changing its behavior.

## Code Quality
- **Linting:** Tools that analyze code for stylistic errors.
- **Code Reviews:** Having peers review your code before it merges to catch bugs and share knowledge.
