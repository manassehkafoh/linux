# 06 CI/CD and Deployment

Getting code from your laptop to production safely and reliably.

## Continuous Integration (CI)
Automating the building and testing of code every time a team member commits changes to version control. This catches integration issues early. Tools include GitHub Actions, Jenkins, CircleCI.

## Continuous Deployment/Delivery (CD)
- **Continuous Delivery:** Code is automatically built and prepared for a release to production. The actual release is manual.
- **Continuous Deployment:** Code is automatically deployed to production without manual intervention if it passes all tests.

## DevOps Culture
Breaking down silos between development and operations. Embracing automation, monitoring, and fast feedback loops.

## Containerization
Using tools like Docker to package an application and its dependencies into a standardized unit (container), ensuring it runs the same way everywhere.
