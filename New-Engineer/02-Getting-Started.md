# 02 Getting Started: Tools and Fundamentals

Before diving into complex architectures, you must master the fundamental tools of the trade.

## Version Control (Git)
Version control is non-negotiable. Git is the standard.
- **Commits:** Represent a logical unit of work. Write meaningful commit messages.
- **Branches:** Isolate features or bug fixes.
- **Merging/Rebasing:** Understand how to integrate changes.

## Development Environment (IDE)
Choose a modern IDE (e.g., VS Code, IntelliJ) and learn its shortcuts, debugging tools, and extensions.

## Basic Programming Principles
- **DRY (Don't Repeat Yourself):** Extract common logic into reusable functions or components.
- **KISS (Keep It Simple, Stupid):** Avoid unnecessary complexity.
- **YAGNI (You Aren't Gonna Need It):** Don't implement features until they are actually needed.
